# 远程服务实板验证 · 2026-11-15

实验室电脑运行 V2.1 远程服务，本机经 Tailscale 连接，服务经实验室电脑的 40GbE 接口访问板卡。已完成远程下载、CRC 校验、播放和 ADC 回采。下面记录实际覆盖的范围，不能推断其他通道或完整实验已通过。

## 单音回环

分别在 DAC 0、2、4、6 播放约 99.964905 MHz、-6 dBFS 单音，每次同时回采八路 ADC，每路 65520 点。四次下载 CRC 均通过；对应 ADC 0、2、4、6 的主峰分别约为 99.964833、99.964821、99.964827、99.964828 MHz，其他 ADC 的最大频谱峰远小于对应通道。板卡未报告故障，对应通道未见明显削顶。DAC 和 ADC 采样率配置分别为 9.8 GSa/s 和 5 GSa/s，并非独立时钟测量。

原始数据、状态和绘图保存在执行电脑的 `host/app_data/remote_captures/even_mapping_20261115_061238/`；采集数据不提交仓库。实验结束时 DAC6 保持单音播放，远程会话已释放；此为当时状态，之后操作前应重新读取。

## 单子带

已用 DAC 2、4 和 ADC 2、4 完成单子带 I/Q 回采，并在本机对三次长采集逐帧离线解调。对应输入、发送参考及分析结果保存在执行电脑 `host/app_data/remote_captures/iq_loop_20261115_050258/` 和 `iq_long_20261115_051134/`。结果是该次采集的有限统计，不能推断所有条件均为零误码。

## 尚待验证

ADC/DAC 1、3、5、7 的物理接线和单路回环，单板四子带与双板六子带收发，Tailscale 端到端吞吐、长时间运行和跨机断线恢复尚待验证。已有服务侧读写时间不能直接当作端到端吞吐。板卡控制需与实验对话协调；服务锁不能阻止其他直接访问板卡的程序。
