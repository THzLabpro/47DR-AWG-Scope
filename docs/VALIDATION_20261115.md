# V2.1 工作台本机验收 · 2026-11-15

本次将同门 V2.1 Python / PySide6 工作台设为唯一维护界面，接入无密码远程服务。验证全部在本机回环模拟器完成，没有访问实验室电脑、板卡、hw_server，也没有运行 Vivado、烧写或测量真实光口速度。本次集成尚未部署到实验室。

## 实现与来源

正式代码位于 `host/tools/awg_gui/`、`host/tools/awg_eth/`。导入同门波形生成、导入、FFT、测量、池化 TX/RX、批量数据协议、原生 DLL 及其 C 源码和模拟器；在其上增加严格版本检查和远程代理。原 MATLAB 启动器与文件 IPC 桥已撤下，历史源码、V1 工程和实验数据保留。

控制服务通过 UDP 9100/9101 对接 D4B/F3，远程传输使用 TCP 4748 和原始样本对。INFO、寄存器身份、ABI、采样率、RAM 与批量端口 BUILD 不匹配即拒绝，拒绝前没有寄存器写入。下载前手动停播；单次采集读回后先释放再分析；连续采集停止后释放。关闭窗口会等待当前请求退出并释放连接，避免销毁仍在工作的 Qt 线程。

本地保存的 CSV + JSON 可重新打开；打开、保存、FFT 和测量不使用板卡。长记录原始样点完整保存，分析取前 262144 点并标注。配置及日志位于 `host/app_data/`，测试通过 `AWG_APP_DATA` 使用独立目录。

## 未完成与限制

V2.1 源码包未包含 `build/F3/package`；现已从同仓库 `awg-eth-v2.1` Release 的 `AWG47DR_V2.1_board_release.zip` 导入完整 D4B/F3 板卡发布包至 `host/hardware/eth40g_v2_1/`。发布 ZIP SHA-256 为 `9760D0E2CE14DB015BC19FC2B1536A45844A2BA07B29EC00C4F9D265CA631339`，与 Release 清单一致；包内八个文件的 SHA-256 均与其清单一致。工作台默认选择该目录及包内 `program.tcl`。固件导入后的自检确认文件齐全；尚未对硬件执行初始化。`host/hardware/program_v21.tcl` 是导入的初始化脚本，本次没有对真实硬件执行。历史 `fpga/` 与 D3C/F1 固件不能充当 V2.1/F3 工程。

实验室服务部署、Tailscale 可达性/速度、真实 D4B/F3 下载与采集、长时间运行和跨机断线恢复待验证。模拟器不代表 RFDC/PHY、时序、真实采样延迟或真实链路吞吐。服务锁不能阻止其他直连 UDP/JTAG 程序，也不能实现多人同时独立使用不同通道。

远程连续采集的停止和关闭在当前请求完成后生效；网络超时可能延长等待。断线不保证 DAC 停止，操作结果不确定时先重新读状态。GUI 展示的板卡读回速度取服务侧数据阶段时间，不能当作 Tailscale 吞吐；总耗时另包含远程传输与本地处理。
