# 共板客户端 v2.1.1

本次发布 47DR 和 RF-UDP 两套 Windows x64 原生客户端，连接同一个实验室服务，显示使用人及排队状态，并在结束使用、关闭窗口或断线超时后自动交接。无需网页，也不用填写预计用时。

## 下载与使用

下载入口：[GitHub v2.1.1 Assets](https://github.com/THzLabpro/47DR-AWG-Scope/releases/tag/shared-clients-v2.1.1)。两个客户端共用此发行页。`git clone` / `git pull` 和页面自动生成的 `Source code` 压缩包只获取仓库源码，不获取下面的客户端附件；RF-UDP 完整工程不在本仓库中。

- `47DR_Shared_v2.1.1_win64.zip`：47DR 波形下载、播放与 ADC 回采客户端。
- `RFUDP_Shared_v2.1.1_win64.zip`：RF-UDP 测试与遥测客户端。
- `SHA256SUMS.txt`：两个压缩包的 SHA-256 校验值。

选择所需客户端，完整解压后运行同名 exe；不要单独移动 exe。客户端无需安装 Python 或 Vivado。先连通实验室 Tailscale 网络，首次启动填写姓名；默认服务地址为 `http://100.121.70.53:4749`，其他实验室需配置自己的服务地址及固件包。

有人占用时，确认加入队列；轮到后会自动加载对应工程并执行已提交任务。关闭窗口或点击“结束使用”释放板卡。网络中断有 30 秒重连宽限，跨工程交接另需等待固件初始化。后台服务重启后须明确执行恢复初始化，旧任务不会重放。

## 验证范围

本次实板验证使用同一电脑上的两个原生窗口和两个独立身份，覆盖正常关窗、RF-UDP 测试运行中关窗、断线超时三种交接。47DR 4096 点零波形播放停止读回、4080 点 ADC 回采通过；RF-UDP 166 包全部正确返回，业务遥测计数一致。发布前 54 项回归检查通过，覆盖共板模块及受影响的旧远程接口、初始化菜单、GUI 和模拟器；两套独立 exe 均通过启动与退出检查。完整验证说明见 [共板验收记录](BOARD_SHARING_VALIDATION_20261117.md)。

两台客户端电脑的人工联合操作、长期稳定性及仪器测量的物理 RF 输出停止尚未验收。RF-UDP 原始比特计数存在待核查的回绕语义，不能使用该计数证明物理层误码率；此项与已通过的业务包回环检查分开。

## 与旧版的关系

这是上位机共享功能更新，沿用原 47DR D4B/F3 固件，未更改 RTL 或重建 bit。实验室服务须使用已部署的 v07／`lab_config_v5.json` 或对应实现；原 4748 服务已停用。新客户端包不包含固件或后台服务。

本次作为默认下载发行版，旧 `awg-eth-v2.1` 发行版保留，其中的固件、脚本接口和历史交接包仍可追溯。本仓库提交 47DR 客户端与公共调度实现；RF-UDP 完整工程仍在独立工程中维护，本发行版附带其已验证的 Windows 客户端，不将本仓库源码压缩包描述为完整 RF-UDP 工程。
