# E6 — GUI 上板試用（D3C 位流）

日期：2026-11-12，使用者同意上板。板卡沿用 E5C 初始化的狀態（`ps_ready=1`）。

## 自動流程（offscreen，GUI 程式碼路徑）

結果存在 `gui_board.json`。

- 連線：`192.168.42.2:9100`，每包 2048 字。
- 生成並下載 8 通道：
  - CH0 是 100 MHz（實際 99.964905 MHz）、−6 dBFS 的正弦；
  - CH1–7 是 300 MHz、−12 dBFS；
  - 每通道 131072 點，**CRC 全部吻合**，0.35 s（5.9 MB/s，含 CRC 指令）。
- 輸出 Run，再做一次起播同步擷取，ADC0 加 ADC1 共 65520 點：
  - 讀回 31 ms，從觸發到算完 50 ms；
  - ADC0 頻率 **99.96483 MHz**，和設定一致；
  - 幅度 −13.7 dBFS，SFDR 44.4 dBc，SINAD 32.8 dB；
  - SINAD 偏低是 CH0 回環線纜上 27–39 MHz 外部干擾造成的，見 E5 報告。
- 連續擷取：3 秒內 50 次（約 16 次/秒），停止後立即停下。
- 錯誤：0。

結束時把輸出停止，接著在桌面開啟 GUI 視窗讓使用者試用。

註：offscreen 平台沒有中文字型，截圖會顯示方框，所以沒有保存截圖。正常視窗的字型顯示正常（E3 模擬器截圖已確認）。
